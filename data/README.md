# data/

| folder | holds | committed |
|---|---|---|
| `youtube/` | Collected datasets, transcribed copies and transcription checkpoints | yes |
| `evidence/pdf/` | Source PDFs of the reference corpus | no (publisher copyright) |
| `evidence/passages/` | Passages extracted from those PDFs, one JSONL per document | yes |
| `evidence/sources.json` | Corpus manifest: which document covers which topic, DOI and publisher. Generated by `python -m rag --build-manifest` from `rag/manifest.py` | yes |
| `index/` | Embedded passage vectors and their metadata. Rebuild with `python -m rag --build-index --no-extract` | yes |
| `labels/` | Video-level ground truth: `ground_truth.json` for the test set, `dev_ground_truth.json` for the dev set, the off-claim audit key | yes |
| `labels/windows/` | Window-level labels used by the sweeps: `chunk_eval_labels*.json` (topic and evidence phrases per window), `prompt_cases.json` (the prompt A/B cases) | yes |
| `results/` | Experiment outputs grouped by protocol version; see `results/README.md` | yes |
| `web_cache*/` | Web-search responses, keyed by query, including page text. Never committed; per run only an index of queries, URLs and retrieval times is kept as `results/<version>/web_cache_index_*.json` | no |

Licence terms for every folder are in `LICENSE-DATA.md` at the project root.

## youtube/

| file | what it is |
|---|---|
| `covid_vaccine_videos.json` / `.csv` | The v1 collection, 143 videos, metadata only |
| `covid_vaccine_videos_transcribed.json` / `.csv` | The same records with `transcript`, `transcript_status`, `detected_language` and `audio_duration_s`. The 119 labelled test videos come from here |
| `covid_vaccine_videos_dev2_mirror_more.json` | Dev candidate pool from the six v1 queries |
| `covid_vaccine_videos_dev2_mirror_selected*.json` | 50 of those, the tuning set, and its transcribed copy |
| `covid_vaccine_videos_dev2_uncovered*.json` | Videos on narratives the corpus does not cover; the selected 21 exercise the web fallback only |
| `covid_vaccine_videos_dev*.json` | The retired first dev set, kept for the record |
| `exclude_dev2.json` | Video ids excluded from dev collection so test material cannot leak into tuning |
| `transcripts_checkpoint*.json` | Per-video progress; what makes a transcription run resumable |

Collection and transcription overwrite their own output in place. The checkpoint
is what accumulates, so a transcribed file is always a fresh projection of it.
